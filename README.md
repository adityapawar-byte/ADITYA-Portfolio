## 🌐 How to Deploy Online for Free (100% Free Hosting)

### Option 1: GitHub Pages (Recommended)
1. Create a free repository named `portfolio` or `aditya-pawar` on [GitHub](https://github.com).
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to **Settings > Pages > Branch: main > Save**.
4. Your website will be live at `https://<your-username>.github.io/<repo-name>/`.

### Option 2: Netlify (Drop & Publish)
1. Go to [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop the `Portfolio` folder.
3. Your portfolio goes live in 5 seconds with a custom URL!

### Option 3: Vercel
1. Import the GitHub repository on [Vercel](https://vercel.com).
2. Click **Deploy**.
